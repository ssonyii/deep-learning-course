# Deep learning coursework (PyTorch)

Homework from the course *Introduction to Deep Learning* at the HSE Faculty of Computer Science. Each notebook contains the code and its outputs.

- `song-year-mlp/`: A fully connected neural network (MLP) in PyTorch that predicts a song's release year from audio features (Million Song Dataset).
- `cifar10-cnn/`: A convolutional classifier for CIFAR-10 in PyTorch, with model design, training and testing, learning-rate schedules, data augmentation, and experiment logging in Weights & Biases.
